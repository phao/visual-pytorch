# Visual PyTorch v0.1.0-alpha.1 — initial public preview

This is a usable research prototype under active construction, not a finished
experiment platform. It is openly AI-coded and jointly human/AI directed.
Original code/documentation are GPL-3.0-only; third-party notices are retained.
The release is source-only: no binary installers or packaged wheels are provided.

## Available now

- Compact PyQt6/WebEngine desktop diagram editor with offline MathJax, floating
  tools, themes, accessibility preferences, resizable/compact blocks and undo/redo.
- Linear/MLP regression, multidimensional named inputs and independent branches,
  ordered Concat, Splitter/Replicator, Reshape and reusable architecture references.
- First CNN workflow: Conv2d/groups, spatial pooling, Flatten and Permute,
  explicit CHW/axis contracts and synthetic spatial-regression data.
- Real isolated CPU PyTorch training, full-batch Adam/MSE, CSV/synthetic data,
  held-out metrics, learned tensors, checkpoints and generated forward source.
- Matching-checkpoint standalone trained export, separate from fresh-weight
  architecture-template export. Stable port bindings prevent silent column reuse.
- `.vtw` SQLite workspaces, exact format/operator documentation and an atomic,
  revision-checked agent/user CLI. Dirty GUI buffers are not silently overwritten.
- Workspace-owned collapsed/expanded layout profiles, Save/reload, undo/redo and
  cross-tab synchronization. Legacy global layout choices are not imported.

The README screenshots are actual sandboxed Qt WebEngine captures of synthetic
workspaces. The CNN example has 128 observations, 17 parameters and 450 updates;
its loss is workflow evidence, not a comparison against published architectures.

## Known limits

Release checks passed: 199 Python tests, 57 JavaScript tests, native Qt workspace
layout/history checks and real sandboxed WebEngine UI/CNN training checks. These
exercise bounded workflows locally; they are not a platform or security certification.

- The current numerical workflow is CPU regression. Classification objectives,
  recurrent/attention networks, full U-Net/ResNet/DenseNet reproduction, symbolic
  architecture families, rich dataset/experiment management and notebook reports
  are not available in this public version.
- Work on richer experiments/reports remains on a separate development branch;
  this release does not advertise that partial implementation as complete.
- RAM admission is an estimate, not a hard memory limit. Save important work and
  start with small runs. Large specifications do not imply local execution support.
- Checkpoints support inference; optimizer-state continuation is not implemented.
  Curve points and held-out values are not statistical confidence statements.
- Undo history is bounded and session-only. Workspaces need explicit Save.
  Layout profiles are workspace-owned; floating-panel positions/visibility are
  still session presentation state, not a portable saved panel arrangement.
- Linux is the exercised desktop platform; other platforms and fresh-install
  combinations remain unverified. See [installation](../install.md).
- Workspace/worker checks are not a hostile-code/file sandbox or a warranty of
  scientific correctness. Independently review exported code and critical results.

Please try the small workflows, open reproducible issues and suggest improvements.
Do not publish private lab data or credentials. See [CONTRIBUTING.md](../../CONTRIBUTING.md)
and [development roadmap](../development.md).
