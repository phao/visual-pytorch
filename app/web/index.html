From drawing to PyTorch

Use Building blocks to add operations. Inputs describe one sample's dimensions; B is the batch dimension. Connect an output socket to an input socket. Use Concat to join independent paths, or Splitter to create branches.

Select a block, then open Inspector to see its settings and tensor contract. Double-clicking a block also opens Inspector. Right-clicking selects it and offers block actions. Its type icon folds details without changing computation.

Validate checks the executable graph. Experiment lets you prepare data, train, inspect learned parameters and read the generated PyTorch forward code. Save workspace keeps architectures and their retained evidence in one .vtw file.

Panels float independently: drag their headings or empty areas, resize at the bottom-right corner, expand with ⤢ and hide with ×. Layout offers workspace-specific block arrangements. Run safety controls execution, not which diagrams you may draw.

About building block

  
Recurrent transition
Choose every Input's role and each state's matching next-state Output. A new independent branch is added; existing blocks and wires are kept. Initial states and controls are supplied data, not learned values. Every exposed root Output needs an explicit task head.
Return sequences
Optional supplied controls
One shared transition owns its parameters once. Masked steps hold state and return zeros; reset restores the supplied initial state before an active step. Full backpropagation across T; no hidden carry between calls.

  
Edit recurrent interface
Advanced explicit bindings. This edits the existing block, not a new branch. Keep stable return port IDs to preserve downstream wires. Removing a connected return port is refused. Affected paths must validate; unrelated drafts are kept. Errors keep your edits here.
Available source socket IDs
sequence_inputs: input + source. states: input + output + port + source. sequence_outputs: output + port. controls: lengths / mask / reset with source + exact adapter. share_with: stable block ID, or null for independent parameters. Change tensor dimensions on their Input boxes. Accepted changes clear legacy attached data/results, keep independent scientific revisions, and form one undo step.
